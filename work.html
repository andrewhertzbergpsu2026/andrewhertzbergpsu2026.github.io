01 / Computer graphics

Recursive
ray tracer

C++ · OpenMP · OpenGL
CMPSC 458 · Fall 2025

I extended the course framework to render spheres and triangles with direct lighting, recursive reflections and refractions, and shadow rays. Four subpixel samples help smooth edges, while OpenMP distributes the pixel loop across CPU threads.

Saved output from my final submission. The renderer is educational; it is not a physically based path tracer.

What I implemented

  • Ray–sphere and ray–triangle intersections, material evaluation and Phong illumination.
  • Recursive secondary rays, total internal reflection handling and transparent-material attenuation.
  • Supersampling, headless output and a camera path for saved animation frames.

02 / Systems programming

Memory and
scheduling

C · Pthreads · Linux · Make
Coursework projects

Two projects focus on decisions that applications usually delegate to the operating system or runtime: how to place allocations and which runnable task should execute next.

Slab and buddy allocator

The allocator combines pools for small objects with power-of-two block splitting and coalescing for larger requests. It gave me a concrete way to reason about internal fragmentation, free lists, and the conditions under which adjacent free regions can be merged.

Allocation request→Size class / buddy block→Reuse / coalesce

Preemptive scheduler

I implemented FCFS, shortest-remaining-time-first and multilevel-feedback-queue policies with synchronized CPU and I/O simulation. Some of the more interesting parts are how policy affects waiting time, how tasks transition between states, and how synchronization preserves those transitions.

These are learning implementations based on class work.

Terrain and transformations

A heightmap becomes a triangle mesh, while keyboard controls translate, rotate, scale and shear scene objects. A camera-relative skybox and a pulsating point light complete the scene.

Roller-coaster simulation

Spline samples define rails, wooden ties and support columns. A second camera mode follows the generated track. The final submission includes a wireframe view for inspecting geometry.

04 / Image synthesis

Texture
quilting

Python · NumPy · Pillow
CMPSC 458 · Fall 2025

This project synthesizes a larger texture from a sample image. It compares candidate patches using overlap error, then uses dynamic programming to choose a low-error seam between the existing image and the new patch.

Saved output from the original submission. Image quilting is inspired by Efros and Freeman (2001).

Two modes, with different assumptions

The baseline uses patch matching. An experimental near-regular mode estimates repeat directions and samples near a lattice. That mode is a simplified approach inspired by a paper, rather than a complete reproduction of their method.

The command-line interface exposes patch size, overlap, candidate tolerance and a random seed, and makes visual comparisons repeatable. The texture quality is dependent on those choices and the input sample.
